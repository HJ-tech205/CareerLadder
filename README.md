##  Featured Projects (Production-Ready)

### 1. Aviator Crash Game: Behavioral Risk & Probability Simulation
* **Core Stack**: R, `tidyverse` (`dplyr`, `ggplot2`), `gridExtra`, LaTeX
* **Domain**: Statistical Modeling, Simulation, Behavioral Analytics
* **Description**: Replicates real-world house edge mechanics via inverse transform sampling to model exponential decay distributions. By tracking cumulative bankroll trajectories across a $10,000$-round sample space, the project empirically proves how high short-term win rates (~64%) create psychological illusions of profit while long-term capital attrition remains mathematically absolute.
* **Key Deliverables**: Automated time-series bankroll trend charts and high-fidelity statistical telemetry matrices.

### 2. Automated ATS CV Screening & Database Ingestion Pipeline
* **Core Stack**: R, SQL, PostgreSQL, Document Parsing Engines
* **Domain**: Data Engineering, ETL Pipelines, Relational Databases
* **Description**: A modular backend data engineering pipeline that automates the ingestion, structural text extraction, and keyword-matching evaluation of Curriculum Vitae (CV) documents. Processed applicant metrics are programmatically validated and streamed directly into a localized relational database layer.
* **Key Deliverables**: Automated parsing scripts, strict relational schema designs, and operational database logging.
